# Aident Brand Visual Production

This repository ships the portable Skill in [`aident-brand-visual-production/`](aident-brand-visual-production/).

Before doing any work, read [`aident-brand-visual-production/SKILL.md`](aident-brand-visual-production/SKILL.md) completely and follow it as the canonical instruction entrypoint. Resolve its relative links from that package directory and load only the references and assets required for the selected production mode.

Keep the complete repository installed. The package relies on its bundled templates, licensed fonts, SVG materials, examples, and validation/rendering scripts; installing this root file alone is not sufficient.
