# Scope and modes

## In scope

- Static marketing exports at the packaged template sizes
- Video production inputs (storyboard, shot list, posters, frame stills)
- Optional authorized final MP4/MOV
- QA-only inspection of returned files
- Return package for marketing-pack ingest

## Out of scope

- Pack copywriting, taxonomy, Lark/Google/Notion pack documents
- Full brand-identity systems / brand books (`aident-brand-design-skill`)
- Creating a GitHub repo as part of this skill install
- Redistributing unlicensed font binaries
- Hard-coding a single paid vendor as the only path

## Mode routing

Pick the **narrowest** mode: `image-kit` | `video-kit` | `both` | `qa-only`.

Editable sources: only when handoff sets the flag **and** user wants source-file handoff; default pack library wants result files only.
